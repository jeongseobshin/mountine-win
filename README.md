# ⛰️ 100대 명산 도장깨기

산림청 선정 100대 명산을 오르고, 정상 인증 사진을 올리면 **완등 도장**이 찍히는 한 페이지 웹앱입니다.
서버 없이 정적 파일만으로 돌아가서 GitHub Pages에 바로 올릴 수 있어요.

## 기능
- **한 페이지 관리**: 100개 산 카드 + 검색 / 권역 필터 / 완등·미완등 / 정렬
- **정상 인증**: 사진 업로드 → 완등 날짜·메모 기록 → 빨간 완등 도장 애니메이션
- **사진 자동 압축**: 긴 변 1080px, WebP(미지원 브라우저는 JPEG), 약 150KB 이하로 자동 축소
  - 목록용 썸네일(360px, 약 30KB)을 따로 만들어 화면이 가벼워요
  - 다시 그려서 저장하므로 위치정보 등 **EXIF는 자동으로 지워져요**
- **게임 요소**
  - XP: 산 높이(m) + 100, 섬 산은 +200 보너스
  - 레벨과 칭호: 등린이 → 동네 뒷산러 → … → 산신령 → 전설의 산악인
  - 배지 26종: 완등 개수, 3대 명산, 1500m 고산, 섬 정복, 에베레스트 누적 고도, 더블 헤더, 사계절, 권역별 정복 등
  - 완등할 때 꽃가루, 레벨 업과 새 배지 안내, 근처 다음 산 추천
- **앱 설치(PWA)**: 사이트를 열면 설치 안내 팝업이 떠요
  - 안드로이드/PC 크롬·삼성인터넷: "앱 설치하기" 버튼 한 번으로 설치
  - 아이폰: 사파리 "공유 → 홈 화면에 추가" 안내
  - 카카오톡 등 앱 안의 브라우저: 외부 브라우저로 열기 안내
  - 설치하면 오프라인(산 위 약한 신호)에서도 열려요
- **앱 아이콘 바꾸기**: ⚙️ 메뉴에서 기본 아이콘, 이모지 아이콘 9종, 내 사진으로 만든 아이콘 중 선택 (이 기기에만 적용)
- **백업/복원**: ⚙️ 메뉴에서 기록과 사진을 JSON 파일 하나로 내려받고 다시 불러오기

## 데이터 저장 위치
기록은 **이 기기 브라우저**에만 저장돼요(localStorage + IndexedDB). 서버로 올라가지 않아요.
기기를 바꾸거나 브라우저 데이터를 지우기 전에는 꼭 ⚙️ → 백업해 두세요.

## 로컬 실행
```bash
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 열면 돼요.

## GitHub Pages 배포
접속 주소: **https://jeongseobshin.github.io/mountine-win/**

- Pages는 `gh-pages` 브랜치에서 배포돼요.
- `main`에 push하면 `.github/workflows/pages.yml`이 `gh-pages`를 `main`과 똑같이 맞추고, 1~2분 뒤 사이트에 반영돼요.
- 휴대폰에서 주소를 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

## 파일 구조
```
index.html          화면 구조
css/style.css       스타일 (다크모드 지원)
js/mountains.js     100대 명산 데이터 (이름, 높이, 권역, 소재지)
js/app.js           앱 로직 (저장, 압축, XP/배지, 백업)
js/pwa.js           앱 설치 안내 팝업, 아이콘 바꾸기
sw.js               오프라인 캐시 (서비스 워커)
manifest.webmanifest 앱 이름·아이콘 정보
icons/              기본 앱 아이콘
```

## 수정하기 쉬운 곳
- 산 정보(높이, 소재지 등): `js/mountains.js`
- 압축 크기와 품질: `js/app.js` 맨 위 `PHOTO`
- XP, 레벨 칭호, 응원 문구: `js/app.js`의 `XP_*`, `TITLES`, `CHEERS`
- 기본 앱 아이콘: `icons/` 폴더의 PNG 파일을 같은 이름·크기로 교체
- 아이콘 프리셋: `js/pwa.js`의 `PRESETS` (이모지, 배경색 2개)
- 앱 파일을 바꾸면 `sw.js`의 `VERSION`을 올려주세요 (설치된 앱도 새 버전을 받도록)
- 배지 추가: `js/app.js`의 `BADGES` 배열에 `{ id, ico, nm, desc, test }` 추가
